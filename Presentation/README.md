# Hugo for Humans — presentation

Open **`Hugo for Humans — presentation.html`** in any browser. It is a single
self-contained file: the stylesheet and all ten screenshots are embedded, so it
works from a USB stick, an email attachment, or a USB-C drive with no network.

Scroll to advance, or use the section links in the bottom bar. `↑` `↓` `PgUp`
`PgDn` and `Home` `End` all work.

## The demo site

"The Deep Dive" is a real Hugo site generated by the app's own code path —
`SiteCreator` and `SiteEngine`, the same functions the wizard calls.

```sh
./Scripts/sample_site.sh      # rebuild it from scratch
./Scripts/site_screenshots.sh # recapture the published pages
```

It is written to `dist/sample/the-deep-dive/`. Five long-form posts across
two sections, with the PaperMod theme installed via Git.

## Regenerating

The deck sources live in `dist/deck/`:

```sh
./Scripts/screenshots.sh                    # re-render the app screenshots
cd dist/deck && python3 capture_slides.py   # review each slide as a PNG
cd dist/deck && python3 build_deck.py       # rebuild the single file
```

`capture_slides.py` writes one PNG per slide to `/tmp/slides` for design review.
It measures real slide geometry rather than guessing offsets, which is why it
renders each slide alone — a full-height render would make every `min-height:100vh`
slide fill the entire canvas.
